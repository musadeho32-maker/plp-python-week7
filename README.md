# Week 7 Assignment: File Handling and CSV Reports

## Files
- `my_notes.py` - Writes, appends, reads, and counts notes.
- `my_notes.txt` - Stores the four notes generated by my_notes.py.
- `report_builder.py` - Reads CSV data, calculates learner results, and creates a report.
- `hubs.csv` - Contains learner names, hubs, and scores.
- `report.txt` - Contains the generated learner performance report.
- `README.md` - Describes the assignment files and explains file handling.

## Reflection
